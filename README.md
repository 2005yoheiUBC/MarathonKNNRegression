# 🏃‍♂️ Marathon KNN Regression Project

This project predicts **marathon race times** based on the maximum training distance per week using **K-Nearest Neighbours (KNN) Regression**.

---

## 📘 Overview
This project explores the relationship between how much a runner trains and how long they take to finish a marathon.  
It uses data visualization, model tuning, and error analysis to make accurate predictions.

---

## 🧠 Features
- Data cleaning and sampling with **Pandas**
- Scaling numeric features using **StandardScaler**
- KNN regression model with **cross-validation**
- Hyperparameter tuning using **GridSearchCV**
- Visualization using **Altair**
- Evaluation using **Root Mean Squared Prediction Error (RMSPE)**

---

## 📊 Results
The model predicts marathon times with an RMSPE of approximately **0.61**,  
meaning it can predict finish times within about **±36 minutes** — decent accuracy!
